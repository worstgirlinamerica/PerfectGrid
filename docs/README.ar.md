Perfect Grid هو تطبيق مجاني مفتوح المصدر للكمبيوتر المكتبي، يُستخدم لإنشاء أوراق اتصال بالفيديو وصور مصغرة للمعاينة من ملفات الفيديو المحلية. ما عليك سوى إدراج مقطع فيديو واختيار التصميم المطلوب، ثم تصدير ورقة اتصال بتنسيق PNG عالية الجودة.

صُمم هذا التطبيق للمحررين وجامعي المحتوى وأمناء الأرشيف وأي شخص يرغب في الحصول على ملخص مرئي سريع لمقطع فيديو.

## الميزات

- إنشاء أوراق اتصال عالية الجودة مع عرض متقدم لبيانات الفيديو الوصفية (الدقة، برامج الترميز، المدة، حجم الملف، إلخ)
- تخطيطات شبكية قابلة للتخصيص بالكامل
- تراكبات اختيارية للرمز الزمني
- اختيار الإطارات الذكي باستخدام **Refine Picks**
- حفظ وإعادة استخدام الإعدادات المسبقة المخصصة
- المعالجة المجمعة
- يعمل على أنظمة ويندوز وماك أو إس ولينكس
> إذا واجهت __أي__ أخطاء، أو لم يعمل شيء ما، أو كانت لديك أسئلة، يرجى إنشاء [تقرير مشكلة](https://github.com/worstgirlinamerica/PerfectGrid/issues/new) للإبلاغ عنها.

## الاستخدام الأساسي

1. افتح برنامج Perfect Grid.
2. اسحب مقطع فيديو إلى داخل النافذة.
3. اضبط تخطيط الشبكة وتصميمها. إذا قمت بتغيير التخطيط، فانقر على **تحديث المعاينة** لإعادة إنشاء الصور المصغرة.
4. جودة المعاينات منخفضة عن قصد — حيث تستخدم عمليات التصدير دائمًا إعداد الجودة الذي حددته.
5. (اختياري) ضمن علامة التبويب **النطاق**، استخدم **تحسين الاختيارات** لاختيار الإطارات بشكل أكثر ذكاءً.
6. اختر جودة التصدير ضمن **النطاق**: **سريع (1080p)**، **تفصيلي (1440p)**، أو **أقصى (4K)**.
7. انقر على **تصدير PNG**.

## التثبيت

قم بتنزيل أحدث إصدار لنظام التشغيل الخاص بك من صفحة [الإصدارات](https://github.com/worstgirlinamerica/PerfectGrid/releases/latest).

### macOS

1. قم بتنزيل ملف `PerfectGrid-v0.1.2-macos-universal.zip`.
2. انقر نقرًا مزدوجًا لاستخراج الملفات، ثم اسحب Perfect Grid إلى مجلد «التطبيقات».
3. افتح ملف `Perfect Grid.app`.

> سيقوم macOS بحظر التطبيق عند تشغيله لأول مرة لأنه غير موقّع. انقر بزر الماوس الأيمن → **فتح** → **فتح** لتجاوز هذا الحظر. إذا لم يفتح التطبيق بعد ذلك، فقم بتشغيل الأمر التالي في «Terminal»: `xattr -cr "/Applications/Perfect Grid.app"`

### Windows

1. قم بتنزيل ملف `PerfectGrid-v0.1.2-Windows-x86_64.zip`.
2. انقر بزر الماوس الأيمن → **استخراج الكل**، ثم افتح المجلد.
3. انقر نقرًا مزدوجًا على `Perfect Grid.exe`.

> قد يحذرك Windows SmartScreen لأن التطبيق غير موقّع برمجيًا. انقر على **مزيد من المعلومات** → **تشغيل على أي حال**.

### Linux

1. قم بتنزيل `PerfectGrid-v0.1.2-Linux-x86_64.AppImage`.
2. اجعله قابلاً للتنفيذ وقم بتشغيله:
```bash
chmod +x PerfectGrid-v0.1.2-Linux-x86_64.AppImage
./PerfectGrid-v0.1.2-Linux-x86_64.AppImage
```

لا حاجة للتثبيت — FFmpeg وجميع التبعيات مدمجة. يعمل على معظم توزيعات x86_64 (Ubuntu 22.04+، Fedora، Arch، إلخ).

> إذا ظهرت لك رسالة خطأ FUSE: `sudo apt install fuse` (Debian/Ubuntu) أو `sudo dnf install fuse` (Fedora).

## الخصوصية

كل شيء يعمل محليًّا. لا توجد تحليلات، ولا قياسات عن بُعد، ولا عمليات تحميل. يتم تضمين FFmpeg و FFprobe.

## ملاحظات

- يدعم صيغ MP4 و MOV و MKV و AVI و WebM وأي صيغة يمكن لـ FFmpeg قراءتها.
- قد يكون فك تشفير AV1 و VP9 بطيئًا على الأجهزة القديمة.
- إصدارات macOS غير موقعة — انظر ملاحظة التثبيت أعلاه.

python -m pip install -r requirements.txt
